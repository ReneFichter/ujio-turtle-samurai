# Bilder

Hier kommen deine Fotos rein, z. B. `toyshot-01.webp`.
Eintragen in `js/content.js` beim jeweiligen Raum unter `gallery`, z. B.:

```js
gallery: [
  { title: "Raphael im Regen", image: "img/toyshot-01.webp" },
  { title: "Kanal-Patrouille", image: "img/toyshot-02.webp" },
],
```

Tipp: Bilder im Hochformat 4:5 (z. B. 1024 × 1280 px) als WebP, je unter 300 KB.
